# Security Policy

## Supported versions

Security fixes go into the latest release tag and the current `main` branch.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** form in the repository's
Security tab. Do not open a public issue for an unpatched vulnerability.

Include the affected version, macOS version, impact, and steps to reproduce.
You should receive a reply within seven days.

OnePlusUI is a user interface package. It makes no network requests, reads no
user files, and stores no credentials.
